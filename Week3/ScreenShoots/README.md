# PHP Array & Function Concepts

This repository contains basic to intermediate PHP examples demonstrating how to work with arrays, multidimensional arrays, built-in array functions, custom functions, and variable scope behaviors.

## Topics Covered

### 1. Multidimensional Arrays & Iteration
* **Multidimensional Arrays:** Storing nested arrays to represent structured data (e.g., student records).
* **Array Iteration:** Looping through arrays using `foreach` loops.

### 2. Built-in Array Functions
* **`is_array()`**: Checks whether a given variable is an array.
* **`in_array()`**: Searches for a specific value inside an array and returns a boolean response.
* **`count()`**: Calculates and returns the total number of elements inside an array.

### 3. Custom Functions & Parameter Handling
* **Default Arguments**: Assigning default parameter values (e.g., `$name = "Ali"`) when calling functions without arguments.
* **Pass by Value**: Passing arguments normally so that changes inside the function do not affect the original variable.
* **Pass by Reference (`&`)**: Passing variables using the `&` operator to modify the original variable's value outside the function.
* **Return Values**: Returning calculated values from functions using the `return` statement.
